# PNG, transparent

Transparent PNGs of the Ethereum Classic logo, rendered from the vector. RGBA with straight (not premultiplied) alpha and an sRGB chunk. The outline is anti-aliased in the alpha only: edge pixels keep the pure facet colour, so there is no fringe on any background. Seams between facets blend the two facet colours. The alpha is an exact mirror image left to right and top to bottom. The number in the file name is the height in px.
